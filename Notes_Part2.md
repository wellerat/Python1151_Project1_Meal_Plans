Project Goals for Part 2 -

Recap of Part 1:

The first part of the project created a meal planner with some meals 
added to a listbreakfast, lunch and dinner.  The user was asked if 
they wanted to add any meals to the any of the three lists, 
breakfast, lunch or dinner.  Then they were asked to enter the meal.
This did get added to the list, but since the output was random, it 
was hard to see the results consistently.

The next step was to ask the user how many days to make the plan, it 
needed to be between 1-7 days.  The user was also allowed to pick 
which day to start the plan.

Once all of the options were completed, the list was displayed on the
terminal for the plan.

Plans for Part 2:

1. Make the planner easier to use.
2. Store data between uses.
3. Allow users to manage thier meal plan
4. The plans will be saved in flies which can be used later
5. Allow the users to view what menu options are available in each category.

In addition to the features, the plan is to add some additonal error handling.
Tests will be created and stored to test the program as it moved forward 
and then these tests will also be used for regression testing to make sure
nothing has been broken.

Additional thoughts to add if time allows:

2. Edit meals
