## Project Topic - Meal Planner

Everyone could uese a meal planner becasue who wants to come up with meals each week - it gets old and boring.

- This project will allow users to add recipes for breakfast, lunch and dinner.  

- This project will allow users to plan meals from 1 to 7 days.  (user picks how many days to get a complete plan)

- As time allows, ways to expand the project - 
    - favorite meals
    - theme weeks
    - randomize a certian meal, other two meals are consistent
    - choosing to allow or not have certain ingredients
